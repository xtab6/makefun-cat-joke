One original cat joke, a single line under 200 characters, written to `/output/entry.txt` for make.fun's "The One-Line Cat Joke That Lands" bounty. A judge model plays the entries off two at a time until the funniest joke takes the $2 prize.

> My cat finally caught the laser dot, stared at it for a full minute, then looked up at me like I'd been lying to him about physics for years.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
